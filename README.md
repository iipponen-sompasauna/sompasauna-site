# sompasauna-site

Sompasaunaseura ry:n **uudet verkkosivut**.

Tähän repoon rakennetaan yhdistyksen uudistettu sivusto, joka korvaa
nykyisen [Sompasauna-repon](https://github.com/iipponen-sompasauna/Sompasauna)
staattiset HTML-sivut (julkaistu osoitteessa https://sompasauna.fi).

## Tarkoitus

- Selkeämpi rakenne ja ylläpidettävyys kuin nykyisessä sivustossa
- Ajantasainen tieto saunasta, aukioloista ja jäsenyydestä
- Pohja, jonka päälle yhdistyksen viestintää voi kehittää

## Tila

Alkuvaihe – sisältö ja tekninen toteutus vielä auki.
